5. Process

The sender opens WhatsApp and chooses a contact
The sender types a message and presses send
The application uses the internet to send the message through WhatsApp's systems
The message is delivered to the recipient's device when the necessary connection is available
WhatsApp displays a delivery or read status when applicable.

Raw Data and meaningful Information

Raw data:

One example of raw data is a WhatsApp message sent to a friend at 10:30, together with its delivery status.

How the system transforms data into information:

WhatsApp processes message and status data to display the conversation in the correct order and show whether a message has been sent, delivered or read, depending on the circumstances and privacy settings.

Meaningful information:

The sender can use the displayed message and its status to understand whether the message has reached the recipient and, when a read status is available, whether it has been read.

This information helps the sender decide whether to wait for a reply or follow up later.

The Fundamentals of Database Design and Information Systems(WhatsApp)

The Five Pillars of an Information System

1. Hardware

Hardware means the physical components you can touch

WhatsApp uses:

Smartphones, tablets and computers to access WhatsApp
Servers that help process and deliver messages
Routers and network equipment that help devices connect to the internet

2. Software

Intangible instructions telling hardware what to do

WhatsApp uses:

The WhatsApp application that allows people to send messages and make calls.
Operating systems such as Android, iOS, Windows and macOS, depending on the device.
Server software that helps process messages and other communication between users.

3. Data

Data intangible collection of facts and figures

WhatsApp uses:

Phone numbers used to identify accounts
Messages sent by users
The date and time a message is sent
Message delivery and read status
Photos, videos, voice notes and documents shared by users
Group names and group membership information

4. People

People are users, developers, system analysts, and database administrators

WhatsApp include:

Users who send and receive messages
Developers who build and maintain the application
Technical support and security teams who help keep the service working
Businesses that communicate with customers through WhatsApp
Network and internet service providers who help users connect to the service

5. Process

A process is structured steps and business workflows governing how tasks are executed

The process of sending a WhatsApp message works like this:

The sender opens WhatsApp and chooses a contact
The sender types a message and presses send
The application uses the internet to send the message through WhatsApp's systems
The message is delivered to the recipient's device when the necessary connection is available
WhatsApp displays a delivery or read status when applicable.

Raw Data and meaningful Information

Raw data:

One example of raw data is a WhatsApp message sent to a friend at 10:30, together with its delivery status.

How the system transforms data into information:

WhatsApp processes message and status data to display the conversation in the correct order and show whether a message has been sent, delivered or read, depending on the circumstances and privacy settings.

Meaningful information:

The sender can use the displayed message and its status to understand whether the message has reached the recipient and, when a read status is available, whether it has been read.

This information helps the sender decide whether to wait for a reply or follow up later.


WhatsApp is an example of an information system because it combines hardware, software, data, people and processes to help people communicate. It uses raw data to provide useful information, such as message history and delivery status.
